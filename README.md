Adhivio

A lightweight Android reminder app built to help you stay on top of your tasks and schedules.

Features
Set and manage reminders easily
Clean, minimal interface
Local notifications so your reminders actually reach you
Tech Stack
React Native with Expo
Firebase
TypeScript
Getting Started
Prerequisites
Node.js (v18 or higher)
Expo CLI
Android device or emulator
Installation

Clone the repository

git clone https://github.com/4kAurora07/adhivio.git

Navigate into the project

cd adhivio

Install dependencies

npm install

Start the app

npx expo start
